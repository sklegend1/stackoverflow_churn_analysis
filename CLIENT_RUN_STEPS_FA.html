۱. هدف این سند

Client Runbook

تمرکز این راهنما روی «اجرا» است، نه تئوری. یعنی دقیقاً چه چیزی را با چه ترتیبی اجرا کنید تا از داده خام به خروجی مدل LSTM برسید.

مخاطب: کاربر نیمه‌فنی (Product/PM/Analyst) که با Command Line آشناست اما قرار نیست وارد تغییر کد شود.

۲. شروع سریع

اگر عجله دارید 
# 1) از ریشه پروژه
pip install -r requirements.txt

# 2) ساخت event log
cd src/data_engineering
python create_eventlog_v2.py

# 3) ساخت feature matrix
python create_feature_matrix.py

# 4) ساخت feature importance برای core activities
python feature_importance_by_xgboost.py

# 5) ساخت core train/eval
python create_core_eventlog_splited.py

# 6) (در صورت نیاز) تولید teacher params با WA_recency
cd ..\models\xgboost
python tp_ap_xgboost_enhanced.py

# 7) آموزش LSTM
cd ..\lstm
python lstm_temporal_ap_tp.py

# 8) ارزیابی چندساله
cd ..\..\evaluation
python lstm_eval_multi_year.py
هشدار: بعضی اسکریپت‌ها path نسبی دارند. برای همین باید در پوشه همان اسکریپت اجرا شوند.

۳. پیش‌نیاز و چک اولیه

قبل از اجرای مراحل
مورد چه چیزی باید وجود داشته باشد چک پیشنهادی
Python نسخه سازگار با requirements python --version
Dependencies کتابخانه‌ها نصب شده باشند pip install -r requirements.txt
داده processed شاردهای پارکت قابل خواندن باشند وجود فولدر data/processed
فایل‌های کلیدی csvها و اسکریپت‌ها موجود باشند وجود فایل‌ها در src و data/processed
نکته مهم: فایل requirements این پروژه UTF-16 است. ظاهر آن ممکن است عجیب به نظر برسد، اما آن را بازنویسی نکنید.

۴. قواعد مهم اجرا

برای جلوگیری از خطا
  1. هر اسکریپت را از پوشه خودش اجرا کنید، نه از هر جای دلخواه.
  2. ترتیب مراحل را تغییر ندهید؛ خروجی هر مرحله ورودی مرحله بعد است.
  3. اگر خروجی یک مرحله ساخته نشد، وارد مرحله بعد نشوید.
  4. برای LSTM، وجود هر دو فایل model و metadata الزامی است.
  5. برای ارزیابی واقعی، باید فایل eval جداگانه ساخته شده باشد.
نکته کاربردی: برای بررسی سریع سالم بودن کد یک اسکریپت بدون اجرای کامل، می‌توانید از python -m py_compile script.py استفاده کنید.

۱۴. کنترل کیفیت و راستی‌آزمایی

After Each Step
  1. فایل خروجی مرحله ساخته شده باشد و حجم آن غیرصفر باشد.
  2. اسکریپت خطای runtime نداده باشد.
  3. ورودی مرحله بعد واقعاً از همین خروجی تامین شود.
  4. برای ارزیابی نهایی، هر دو فایل model و metadata وجود داشته باشند.
نکته: برای ارائه به مشتری، بهتر است بعد از هر مرحله یک screenshot از نام فایل خروجی و timestamp تولید آن نگه دارید.

۱۵. عیب‌یابی رایج

Troubleshooting
مشکل علت احتمالی راه‌حل
File not found اسکریپت را از پوشه اشتباه اجرا کرده‌اید. به پوشه همان اسکریپت بروید و دوباره اجرا کنید.
عدم تولید core train/eval create_core_eventlog.py اجرا شده، نه نسخه splited create_core_eventlog_splited.py را اجرا کنید.
LSTM اجرا نمی‌شود teacher file یا persona stats یا core activity csv پیدا نشده وجود فایل WA_recency و nmf_cluster_statistics_20 را چک کنید.
Evaluation ناقص است metadata یا model checkpoint وجود ندارد آموزش LSTM را کامل کنید تا هر دو فایل تولید شود.
نتیجه: اگر مراحل 0 تا 5 را با همین ترتیب و همین checkها اجرا کنید، مسیر کامل پروژه از داده خام تا ارزیابی LSTM قابل تکرار خواهد بود.
